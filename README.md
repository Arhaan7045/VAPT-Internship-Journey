# VAPT Internship Journey 🔐

This repository documents my learning and hands-on practice during my Vulnerability Assessment and Penetration Testing (VAPT) internship.

## 🎯 Goal

Build a strong beginner-level understanding of:

- Linux fundamentals
- Networking
- Nmap and reconnaissance
- Web application security
- OWASP Top 10
- Burp Suite
- Vulnerability assessment
- Penetration testing methodology
- Vulnerability reporting
- Remediation

## 📚 Learning Approach

For each topic, I follow:

> Learn → Practice → Document → Revise

I focus on understanding:

- What the concept means
- Why it is used
- How it works
- How vulnerabilities can be identified
- Impact
- Remediation

## 🧪 Practice Environment

All practical security testing documented here is performed only against:

- TryHackMe labs
- Intentionally vulnerable applications
- CTF/lab environments
- Systems for which I have explicit authorization
